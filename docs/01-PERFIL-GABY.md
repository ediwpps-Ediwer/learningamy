## Errores típicos de un hispanohablante que voy a vigilar

Esto es lo que hace que el semáforo se ponga amarillo, y no es "estar mal": es
transferencia del español. Vale la pena tratarlo aparte porque se corrige distinto.

| Sonido en inglés | Qué suele salir | Ejemplo |
|---|---|---|
| `th` (think, three) | `t` o `d` o `tree` | no existe en español |
| vocal corta vs larga | se colapsan | `ship` / `sheep`, `bit` / `beat` |
| `v` | suena como `b` | `van` / `ban` |
| `s` inicial + consonante | se le agrega `e` | `school` → `eschool` |
| `h` inicial | se pierde | en español la `h` es muda |
| `z` | suena como `s` | `zoo` / `sue` |
| `j` / `y` | se confunden | `jet` / `yet` |
| consonante final | se cae | `cat` → `ca` |

**Estos pares van precargados en el motor** como "confusiones esperadas", para
marcarlos amarillo y no rojo, y para que la corrección le muestre el contraste
(oír `ship` y `sheep` uno detrás del otro).
